# F3.2 prep: slot numbers and Renumber mode

Module: `tool/web/src/utils/layout/slotNumbering.ts` (tests alongside).

```ts
effectiveSlotNumbers(slots, placementMode, templateWidth): number[]   // result[slotIndex] = 1-based number
applyRenumberSequence(slots, clickedIndices): { slots, order }        // order[newPos] = oldIndex
remapSlotAssignmentsAfterReorder(assignments, order): Record<number, number>
```
Integrator: draw `effectiveSlotNumbers(...)[i]` on each slot in `TemplatePreview.tsx` (it inverts the existing
`computeSlotNumberToIndex`, so numbers match placement). In Renumber mode collect clicks, then apply
`applyRenumberSequence`, set `slots`, remap `slot_assignments`, and push one history step.
Decision: unclicked slots keep relative order after the clicked ones; duplicate/invalid clicks ignored.
