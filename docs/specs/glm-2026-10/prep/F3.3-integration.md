# F3.3 prep: handle scale, zoom/pan, keyboard nudge

Module: `tool/web/src/utils/layout/viewport.ts` (tests alongside).

```ts
handleRadiusImagePx(displayScale), strokeWidthImagePx(displayScale)   // 8 / 2 CSS px in template px
zoomAt(viewport, factor, anchor), panBy(viewport, dx, dy), screenToImage(pt, viewport, baseScale)
clampZoom(z)  // 0.25..8
nudgeBox(box, key, shift, templateSize): Box | null   // arrows 1px, shift 10px, size preserved, clamped
```
`displayScale` = fitted CSS px per template px times `viewport.zoom`. Integrator: in `TemplatePreview.tsx`
use these for handle radius/stroke, draw handles only for the selected box, apply the viewport transform,
wheel -> `zoomAt`, space-drag -> `panBy`, arrow keydown on the selected box -> `nudgeBox` (preventDefault when non-null).
Nudge pushes history with a coalesce key (F3.4). Viewport state is local UI state, not persisted.
