# F3.1 prep: add / duplicate / delete slots

Module: `tool/web/src/utils/layout/slotOps.ts` (tests: `slotOps.test.ts`). Pure functions, not wired in.

```ts
addSlot(slots, size): { slots, selectedIndex }
duplicateSlot(slots, index, size, offset = 20): { slots, selectedIndex }
deleteSlot(slots, index): { slots, selectedIndex | null }
remapSlotAssignmentsAfterDelete(assignments, deletedIndex): Record<number, number>
createDefaultSlot(existing, size): TemplateSlots   // median-sized, canvas-centred
```
`size` = `{ width, height }` of the template (`templateSize` in App.tsx). Inputs are never mutated.

Integrator: call from the Template-step toolbar handlers, then set `slots` and the selected index.
Confirm before `deleteSlot` (spec). After delete, run `remapSlotAssignmentsAfterDelete` on `slot_assignments`.
Wrap each call in a history push (F3.4). Old sessions are unaffected (nothing calls these yet).

Decisions: new slot box offsets/sizes are per-box medians relative to the mugshot; with no slots,
proportions of the canvas are used. Duplicate goes right after the source; near the right/bottom edge
it shifts by -offset instead so it never overlaps exactly. Out-of-range index returns the same array (no-op).
Not covered: removing baby/quote boxes for slots (the spec allows them missing, but `TemplateSlots` requires all four; needs a schema decision).
