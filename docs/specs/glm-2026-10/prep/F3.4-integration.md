# F3.4 prep: undo / redo history

Module: `tool/web/src/utils/layout/history.ts` (tests alongside). Generic over snapshot type.

```ts
createHistory(initial, limit = 50): History<T>     // limit floor is 50
pushHistory(h, next, coalesceKey?): History<T>     // ignores equal state; same key merges a drag into one step
undo(h), redo(h), canUndo(h), canRedo(h), resetHistory(h, value)
historyShortcut(keyboardEvent): "undo" | "redo" | null   // Ctrl/Cmd-Z, Shift-Ctrl/Cmd-Z, Ctrl-Y
```
Integrator: snapshot = `{ slots, slotAssignments }` (and anything else a layout edit touches: regroup, re-parse,
reset slot, add/delete). Hold `History<Snapshot>` in `App` state; undo/redo write `present` back to those states.
Drag/resize/nudge pass a per-gesture key (e.g. `drag-${id}`). Call `resetHistory` on new template upload or session restore.
Not persisted (do not add to `PersistedSessionV1`). Equality uses JSON compare; snapshots must be plain data and treated as immutable.
Note: a coalesce key only merges when a prior step exists; first push of a burst always adds one step.
