# F1.6 prep: real weights and italic

Partial, not integrated. `font_styling.resolve_styled_font_file(workspace_id, family, bold, italic=False)` preserves uploaded-before-system resolution; italic scores capable faces ahead of upright. `load_styled_font(workspace_id, family, weight, size, font_style='normal', warnings=None)` returns a fresh Pillow font, configuring fvar axes in file order (wght=400/700, ital=0/1, slnt=0/-12, clamped). Upright fallback and axis failure append plain-English warnings. Uses existing fontTools/Pillow only; no change to fonts.py.

Integrator supplies load_font=lambda size: load_styled_font(..., size, font_style, warnings) to render_text. Important default conflict: applying wght on legacy variable-font normal/bold sessions can change existing pixels. Keep the base loader for legacy sessions (missing new style fields) and opt into the new loader explicitly. This must be resolved in the integration migration contract; helpers alone cannot promise unchanged variable-font defaults and also corrected historical weights.

Tests cover axis ordering/clamping with a fake variable font, normal selector parity, missing italic and real installed oblique when present. Actual variable font rasterisation and upload/UI/session/e2e coverage remain unverified. Uploaded filename is exact-file selection; italic cannot switch faces in that mode.
