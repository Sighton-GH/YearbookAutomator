# F1.2 prep: text colour

Partial, not integrated. `text_color.parse_text_color(value)` accepts optional # and three/six hex digits, matching existing baby colour format; returns RGB tuple or raises ValueError. `TextStyle.color` defaults to #141e32. The integrator must validate schema fields, send name_color/quote_color to the separate TextStyle values, and wire picker/session/config fields. Explicitly passing the default hex still takes the exact base-pixel path. Tests cover formats, rejection and actual red glyph pixels. TIFF and UI/e2e remain unverified.
