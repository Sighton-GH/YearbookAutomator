# F1.3 prep: spacing

Partial, not integrated. TextStyle gains line_spacing (None or 0.5-3.0 font-size multiple) and letter_spacing (-5 to 50 output pixels). `text_spacing.glyph_positions(text, font, letter_spacing)` returns per-glyph positions using pair getlength differences; `tracked_bounds` and `draw_tracked` share those positions. Zero tracking preserves whole-run shaping. Feed the exact name_/quote_ fields into TextStyle after schema/session/config wiring.

Decision: explicit line spacing defines baseline step as size*multiple; None uses Pillow's A-bbox bottom, matching legacy quote spacing=0. Tracking uses codepoints, not grapheme clusters; complex-script tracked text is not yet reliable (F1.7 reports warning). Tests verify pair kerning, width and range bounds. Defaults retain base rendering; UI/e2e unverified.
